# Prior cutover design feedback

前一版由助手设计并交给 GLM 执行的生产切换方案质量不可接受。后续设计必须由方案作者承担失败路径正确性，不把方案缺陷归因于执行 Agent；避免以复杂状态机、dry-run 和大量检查代替对真实关键路径与回滚路径的验证。当前 blue-green 应保持独立、最小且可人工审阅。
